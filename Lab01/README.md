### Huong dan Lab01
# Lab 01 - Chương trình Thông tin cá nhân

## Thông tin sinh viên

* Họ tên: Nguyễn Thanh Thủy
* MSSV: 50.01.104.160
* Lớp: 50.CNTT.C

## Mô tả

Ứng dụng WinForms cơ bản cho phép người dùng nhập và hiển thị thông tin cá nhân.

## Chức năng

* Nhập thông tin cá nhân: Họ tên, năm sinh, email.
* Chọn giới tính (RadioButton) và chọn Khoa (ComboBox).
* Giao diện thiết kế trên Windows Forms ứng dụng C#.

## Cách chạy

1. Mở file `.sln` bằng Visual Studio
2. Build solution
3. Chạy project
